# Contributing to Imgsharer

Thanks for your interest in improving Imgsharer.

## Before you start

- Search existing issues and pull requests before opening a duplicate.
- For larger changes, open an issue first so the scope can be discussed.
- Never commit API keys, tokens, passwords, private URLs, or production credentials.

## Development

```bash
pnpm install
pnpm dev
```

Before opening a pull request, run:

```bash
pnpm lint
pnpm build
```

## Pull requests

Please keep pull requests focused and describe:

1. What problem the change solves.
2. What changed.
3. How you tested it.
4. Any screenshots or reproduction steps when relevant.

Useful contribution areas include UI/accessibility, image-processing workflows, performance, wallpaper tooling, documentation, and tests.

## Code of conduct

Be respectful and keep technical discussions focused on the project and the work being reviewed.
